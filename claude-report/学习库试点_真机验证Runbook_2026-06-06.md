## A. 怎么"开"（唯一需要的代码改动，很小）

试点入口已经接进 app，但配置默认 `.disabled` 且 app 构造时没传它，所以**必须显式打开**。开关用现成工厂函数（在 `CanonicalLibraryMetadataLanding.swift`）：

- `CanonicalLibraryMetadataDebugPilotConfiguration.diagnosticsOnly()` —— 零副作用，只比对
- `.armTestRootN1(token:evidence:)` —— 武装 1 对象金丝雀（测试根，不提交）
- `.executeTestRootN1(token:evidence:)` —— 1 对象真提交到**测试根** + 回滚
- `.executeProductionRootN1(token:evidence:allowProductionRootWrites:)` —— 1 对象真提交到**真实根**（第一次真写）

**让 Codex 做这一件小事**（这是真正能解锁的工作，别再让它加脚手架）：
> 在 `IPhoneSettingsView.swift` / `MacSettingsView.swift` 加一个**隐藏 Debug 开关**（默认 off），运行时选择上面 4 个模式之一，把选中的 config 注入 `StudyLibrarySyncCoordinator`（iPhone，构造点 `MacConnectionView.swift`）与 `SecureReceiverService`/`SecureLocalHTTPSServer`（Mac，构造点 `RokuricsMacApp.swift`）。**默认仍 `.disabled`。**

有了这个开关，后面四档都不用重编译，真机上直接切。

## B. 测什么（一次只升一档，每档过了再升）

前置：iPhone 与 Mac 已配对、学习库里有几个文件夹/学习项、能触发同步（前台/手动同步各跑几次）。

| 档 | 动作 | 期望 | 风险 |
| --- | --- | --- | --- |
| 1 `diagnosticsOnly` | 切到该模式，触发几次同步 | 读侧**等价**、冻结护栏**无违规** | 零（不写不切） |

## C. 在哪看反馈（真证据，非直观感受）

### C1. 两个诊断文件
- **iPhone**：app Documents → `Rokurics/Sync/Diagnostics/connection-diagnostics.jsonl`
  （用「文件」App 或 Xcode → Devices & Simulators → 选 app → Download Container 取出）
- **Mac**：`~/Library/Application Support/Rokurics(或 RokuricsLocal)/Sync/Diagnostics/connection-diagnostics.jsonl`
- 另有 **`canonical-shadow.jsonl`**（canonical vs legacy 逐对象差异），同目录族下。

### C2. 单一最佳产物
`CanonicalLibraryMetadataEndToEndPilotReport`（事件名 `canonicalLibraryMetadataEndToEndPilotReportGenerated`）——一份端到端汇总报告，直接看它最省事。

### C3. 在 jsonl 里 grep 这些事件名
**要看到（绿）：**
```
canonicalLibraryMetadataReadSideEquivalent
canonicalLibraryMetadataReadSideParallelEquivalent
canonicalLibraryMetadataLandingReadSideEquivalent
canonicalLibraryMetadataCanaryStageCompleted
canonicalLibraryMetadataEndToEndPilotReportGenerated
```
**必须为 0（红，出现就停）：**
```
canonicalLibraryMetadataReadSideDivergent
canonicalLibraryMetadataReadSideParallelDivergent
canonicalMigrationLandingFreezeViolation
canonicalLibraryMetadataCanaryStageFailed
canonicalLibraryMetadataCanaryStageBlocked
```
命令示例（Mac 上）：
```sh
cd ~/Library/Application\ Support/Rokurics*/Sync/Diagnostics/
grep -oE 'canonicalLibraryMetadata[A-Za-z0-9]+|canonicalMigrationLandingFreezeViolation' connection-diagnostics.jsonl | sort | uniq -c | sort -rn
```
